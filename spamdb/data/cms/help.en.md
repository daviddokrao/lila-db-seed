# Contribute

HungKings is small. Every one of these helps, and the first one helps most.

## Report what is broken

Playing here and telling us when something misbehaves is genuinely the most
useful thing you can do. A bug nobody reports is a bug nobody fixes. The
[contact page](/contact) routes each kind of problem to the right place — and
please read it first, because several common surprises (en passant, castling
through check, insufficient material) turn out to be the rules of chess rather
than bugs.

## Improve the Vietnamese

The Vietnamese interface is translated but not polished. If a phrase reads
awkwardly, or a chess term is not the one Vietnamese players actually use, tell
us which string and what it should say. Chess vocabulary is exactly the kind of
thing that needs players, not translators.

## Write code

The [source](/source) page lists the repositories. Issues and pull requests are
welcome. If a change would be useful to every Lichess fork and not just to us,
consider sending it [upstream](https://github.com/lichess-org/lila) instead —
it will reach far more people that way.

## Play

A chess server with no players is just software. Finding an opponent is the
feature that everything else depends on, and it is the one thing we cannot build
ourselves. Bring a friend.
