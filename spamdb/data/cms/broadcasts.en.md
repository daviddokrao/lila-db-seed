# About broadcasts

A broadcast follows a real tournament move by move, so you can watch games from
an over-the-board event here, with the analysis board, the engine and the chat
you are used to.

## Watching

Open [broadcasts](/broadcast) for what is running now and what is coming up.
Each round shows every game at once; click one to follow it on a full board.

You can turn the engine on while watching, browse the moves without losing the
live position, and jump back to the current move at any time. Everything stays
available afterwards, so a finished broadcast is a searchable archive of the
event.

## Running one

Anyone can create a broadcast. You will need a source for the moves — either a
public PGN address that a tournament's software updates as games go on, or
electronic boards feeding results in.

Set up the tournament, then add a round for each playing session with its start
time and its source. Rounds go live by themselves at the time you set.

If you want us to feature a tournament, or you are running something with the
organiser's blessing and want help, get in touch through the
[contact page](/contact).

## Please note

Only broadcast an event you are entitled to relay. Some organisers restrict
redistribution of their moves, and that is their call, not ours.
